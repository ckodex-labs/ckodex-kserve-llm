# Security Policy

## Supported Versions

We only support the latest version of the CKodex KServe LLM Operator. Production users are encouraged to stay up to date with the latest releases to ensure they have the latest security patches.

| Version | Supported          |
| ------- | ------------------ |
| v0.2.x  | :white_check_mark: |
| v0.1.x  | :white_check_mark: (LTS until v0.3.0) |
| < v0.1  | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please do NOT open a public issue. Instead, please follow these steps:

1. **Email us**: Send a detailed report to <security@ckodex.org>.
2. **Details to include**:
   - Description of the vulnerability.
   - Steps to reproduce.
   - Potential impact.
   - (Optional) Suggested fix.
3. **Response time**: You will receive an acknowledgment within 48 hours.
4. **Embargo**: We ask that you keep the vulnerability confidential until we have released a fix and provided an update.

## Our Process

1. **Verification**: We will verify the report and determine the impact.
2. **Fix**: We will work on a fix as a high priority.
3. **Disclosure**: Once a fix is released, we will publish a security advisory and credit the reporter (unless they choose to remain anonymous).

Thank you for helping us keep the community safe!
