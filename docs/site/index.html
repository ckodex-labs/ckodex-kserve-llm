What it does

The operator reconciles LLM inference intent into Kubernetes resources, gateways, and status conditions for platform teams and model operators.

Where to start

Follow the getting-started guide for local deployment, then use the small CPU fixture to exercise a local inference flow.

Verification

Run the repo’s Dagger-based verification pipeline locally before release or promotion to collect the operator’s contract and test evidence.
